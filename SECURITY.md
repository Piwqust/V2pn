# Security

## Reporting a vulnerability

Please do not open a public issue. Report privately through [Security → Report a vulnerability](https://github.com/Piwqust/V2pn/security/advisories/new) in this repository; only the maintainers see it.

Include the V2pn version, the operating system, what happens and how to reproduce it. Do not send subscription links or server addresses: they carry your access key.

What counts as a vulnerability in V2pn:

- installing an update that is not signed with the release key, or getting around the package check;
- running someone else's code or gaining privileges through V2pn or its updater (AmazTool);
- leaking server keys, subscription links, or traffic outside the chosen mode;
- access to the local proxy or the core's API from the network or from another program when the user did not turn it on.

Report flaws in the cores themselves (Xray, sing-box, mihomo) and in the protocols to their authors; if V2pn makes such a flaw worse, report it here too.

Fixes ship in a new version. Only the latest version is supported: V2pn updates itself.
