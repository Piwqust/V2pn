# V2pn для провайдеров: оформление партнёра

[In English](README.md)

VPN-провайдер может оформить V2pn для людей со своей подпиской: своё имя и знак, свой цвет и один из пяти видов, которые рисует V2pn. Подключение, серверы, настройки и состояние защиты остаются за V2pn. Человек в любой момент переключается между обычным V2pn и оформлением провайдера.

Эта страница для разработчиков провайдера: что отдавать, как это подписывается и проверяется и что покажет V2pn.

## Что получает провайдер

| | Любая панель | Партнёр (сертификат от V2pn) |
| --- | --- | --- |
| Название подписки, трафик, срок, объявление, кнопки поддержки и кабинета (стандартные заголовки) | да | да |
| Баннеры, напоминание о продлении, подключение при запуске, порядок серверов, обновление и проверка при запуске (заголовки Happ, INCY и v2RayTun) | да | да |
| Переезд подписки на другой ваш домен (`new-url`, `new-domain`) | нет | да |
| Ссылки `v2pn://add` с сайта или из бота провайдера | да | да, и V2pn пишет, что провайдер — подтверждённый партнёр |
| Знак провайдера на его подписке в списке V2pn | нет | да |
| Оформление V2pn провайдера (пять видов, цвет провайдера) | нет | да, с правом `edition` |
| Тариф, состояние серверов по проверке провайдера, устройства, сбои в оформлении | нет | да, с правом `account` и API |
| Описание серверов (группы, страны, назначение) и до четырёх своих кнопок | нет | да, с правом `actions`, его получает каждый партнёр |
| Закрытые настройки: скрытые адреса серверов, ссылку нельзя переслать | нет | да, с правом `lock` после ручной проверки |

## Как это работает

1. Подписка провайдера отвечает с заголовком `v2pn-partner`: это адрес папки с подписанным пакетом.
2. После каждого обновления подписки V2pn скачивает из этой папки `cert.json` и `partner.json` и проверяет:
   - `cert.json` подписан корневым ключом партнёров V2pn, не истёк и не отозван;
   - `partner.json` подписан ключом, который назван в сертификате;
   - подписка и папка лежат на доменах из сертификата;
   - каждая картинка совпадает по размеру и SHA-256 с `partner.json`.
3. Если всё сошлось, V2pn сохраняет пакет и один раз предлагает оформление: «Открыть оформление <провайдер>» или «Остаться в обычном V2pn».
4. Человек переключает оформление названием в заголовке окна, в меню трея, клавишами Ctrl+1…9 (⌘ на Mac) или на странице «Оформление». Там же он настраивает вид: светлый или тёмный, акцент.

Если пакет не прошёл хотя бы одну проверку, он не используется: V2pn остаётся обычным, а в окне подписки написано, что оформление провайдера не прошло проверку. Серверы при этом работают как обычно.

## 1. Ключи и сертификат

Создайте пару ключей (ECDSA P-256), закрытую часть храните у себя:

```
dotnet run tools/partner.cs -- new-key provider-key.pem
```

или через OpenSSL:

```
openssl ecparam -name prime256v1 -genkey -noout -out provider-key.pem
openssl ec -in provider-key.pem -pubout -outform DER | base64
```

Пришлите владельцу V2pn:

- id партнёра: строчные латинские буквы, цифры и дефис, 2–32 символа (`configra`);
- имя, которое увидят люди: до 40 символов, без «V2pn»;
- домены, с которых отдаются подписка и пакет (`example.com`, `*.example.com`);
- открытый ключ (base64 от DER SubjectPublicKeyInfo, как выше);
- нужные права: `edition` (оформление), `account` (API) и, если нужно, `lock` (закрытые настройки, после ручной проверки). `actions` (кнопки и описание серверов) получает каждый партнёр.

V2pn до 1.0.3 включительно не принимал сертификат с правами, которых не знал: с правом `actions` оформление там не откроется, пока человек не обновит V2pn. Новые версии пропускают неизвестные права.

В ответ придут `cert.json` и `cert.json.sig` сроком на год. Положите оба файла в папку пакета как есть.

## 2. Пакет

Папка, которая отдаётся по https по адресу из заголовка `v2pn-partner`:

```
https://example.com/v2pn/
  cert.json          от владельца V2pn
  cert.json.sig
  partner.json       ваш, подписан вашим ключом
  partner.json.sig
  logo-light.png     картинки, названные в partner.json
  logo-dark.png
  mark.png
  lamp.webp
```

`partner.json` ([JSON-схема](partner.schema.json)):

```json
{
  "schema": 1,
  "id": "configra",
  "name": "Configra",
  "brand": {
    "accent": "#FF7A2F",
    "logo": "logo-light.png",
    "logoOnLight": "logo-dark.png",
    "mark": "mark.png"
  },
  "edition": {
    "variants": ["cabinet", "signature", "warm", "studio", "ascii"],
    "default": "cabinet",
    "art": { "lamp": "lamp.webp" }
  },
  "links": { "cabinet": "https://example.com/cabinet", "support": "https://t.me/example_support" },
  "api": "https://example.com/v2pn/api/",
  "assets": [
    { "name": "logo-light.png", "size": 10913, "sha256": "f602…cf08" }
  ]
}
```

| Поле | Что с ним делает V2pn |
| --- | --- |
| `id` | должен совпадать с id партнёра в сертификате |
| `name` | показывается в заголовке, переключателе и интро; до 40 символов, без «V2pn» |
| `brand.accent` | `#RRGGBB`; акцент оформления, пока человек не выбрал другой |
| `brand.logo`, `brand.logoOnLight` | широкий логотип для тёмного и светлого заголовка: от 2:1 до 8:1, 32–256 px в высоту, прозрачный фон (подойдёт 340×96) |
| `brand.mark` | квадратный знак на прозрачном фоне для карточки подписки: 64–512 px (подойдёт 128×128) |
| `edition.variants` | какие из пяти видов вы разрешаете, в порядке списка |
| `edition.default` | вид, который откроется первым |
| `edition.art.lamp` | картинка для вида «Студия»: 200–1600 px по каждой стороне, не шире 2:1; вырезанный предмет на прозрачном фоне стоит прямо на странице, картинка со своим фоном показывается в рамке, как фото |
| `links.cabinet`, `links.support` | кнопки в оформлении, если в заголовках подписки их нет |
| `api` | базовый адрес вашего API (с правом `account`, на домене из сертификата) |
| `assets` | каждая картинка с размером и SHA-256; заполняет `tools/partner.cs pack` |

Картинка, которая не подходит под своё место, там не показывается (V2pn покажет имя или ничего), а `tools/partner-check.cs` скажет, какая и почему; остальной пакет работает.

Чего пакет не задаёт — нарочно: шрифты, скругления, отступы и все цвета, кроме акцента. У каждого вида свой шрифт и своя форма, а остальные цвета для светлого и тёмного V2pn выводит сам и проверяет, что текст читается (WCAG AA, 4,5:1). Акцент идёт на кнопки и метки как есть; там, где он становится текстом на светлом фоне, V2pn затемняет его ровно настолько, чтобы читалось. Акцент, похожий на зелёный «защищено» или жёлтый «внимание», V2pn сдвигает от них. Благодаря этим ограничениям каждый вид работает при любом размере окна, в светлом и тёмном, у любого провайдера.

Ограничения: `partner.json` до 64 КБ, `cert.json` до 16 КБ, не больше 8 картинок, только PNG, WebP или JPEG, до 1 МБ каждая, имена файлов без папок.

Подписывайте `partner.json` после каждого изменения:

```
dotnet run tools/partner.cs -- pack <папка пакета> --key provider-key.pem
```

или своими средствами: ECDSA P-256 над SHA-256 точных байтов `partner.json`, подпись DER в base64 в файле `partner.json.sig`. Отдавайте файлы байт в байт, без перекодировки концов строк: V2pn проверяет те байты, которые получил.

## 3. Серверы и кнопки

С правом `actions` (его получает каждый партнёр) пакет описывает серверы подписки и задаёт до четырёх своих кнопок. Кнопка — это подпись, значок и действие из каталога V2pn: своей логики в приложении у провайдера нет. Решение о сервере принимает либо V2pn по своим замерам, либо ваш API.

### Описание серверов

```json
"servers": [
  { "name": "🇩🇪 Германия 2", "group": "Основные", "country": "DE", "city": "Берлин",
    "purpose": ["youtube"], "priority": 5, "note": "Быстрый канал до Европы" },
  { "host": "nl1.example.com", "group": "Для игр", "purpose": ["games"] },
  { "name": "Резерв", "hidden": true }
]
```

| Поле | Что делает V2pn |
| --- | --- |
| `name` или `host` | находит сервер вашей подписки: по точному имени (как в ссылке) или по адресу; хотя бы одно из двух обязательно |
| `group` | до 24 символов; заголовок в списке серверов подписки и в оформлении. Группы идут в том порядке, в каком впервые встречаются в пакете, серверы без группы — в конце, под «Другие» |
| `country` | код ISO 3166 из двух букв: флаг и место на карте вместо догадки по имени |
| `city` | до 32 символов, строкой под именем |
| `purpose` | для чего сервер: `youtube`, `games`, `mobile`, `whitelist`, `streaming`, `ai`, `torrents`. V2pn пишет это словами («YouTube», «Игры», «Мобильный интернет», «Белые списки», «Стриминг», «Нейросети», «Торренты») меткой на строке сервера. Другие значения пропускает |
| `priority` | целое от −1000 до 1000; при равных замерах выбирается сервер с большим |
| `hidden` | `true`: сервер не показывается и не предлагается. Подключиться к нему можно только по рекомендации вашего API |
| `note` | до 60 символов, строкой под именем |

Поле длиннее предела V2pn не показывает (обрезанной строки не будет), а `partner-check` скажет какое. Записей не больше 300.

### Кнопки

```json
"actions": [
  { "id": "fast",   "label": "Самый быстрый",    "icon": "bolt",   "do": "connect.best", "strategy": "ping" },
  { "id": "stable", "label": "Самый стабильный", "icon": "shield", "do": "connect.best", "strategy": "stable", "scope": { "group": "main" } },
  { "id": "yt",     "label": "Для YouTube",      "icon": "play",   "do": "connect.recommend", "purpose": "youtube" },
  { "id": "renew",  "label": "Продлить",         "icon": "card",   "do": "open.renew" }
]
```

`id` — строчные буквы, цифры, `-` и `_`, до 32 символов; `label` — до 24 символов; `icon` — один из значков V2pn: `bolt`, `shield`, `play`, `game`, `card`, `chat`, `globe`, `star`, `refresh`, `check`, `info`, `gift` (с другим кнопка будет без значка).

| `do` | Что делает V2pn |
| --- | --- |
| `connect.best` | проверяет серверы и подключает к лучшему по `strategy`: `ping` — наименьшая задержка сейчас; `stable` — больше всего ответов за последние 10 проверок V2pn, потом наименьшая медиана, потом наименьший разброс; `load` — наименьшая нагрузка из `GET servers` (без чисел нагрузки — по пингу). `scope` сужает выбор: `group`, `purpose` или список `servers` (имена или адреса) |
| `connect.recommend` | спрашивает `GET <api>recommend?purpose=<purpose>` и подключает к первому серверу из ответа, который есть в подписке и отвечает. Если API не ответил или никто из названных не отвечает — к самому быстрому серверу с этим назначением. Нужен API |
| `connect.server` | к серверу `server` (имя или адрес) |
| `connect.group` | к самому быстрому серверу группы `group` |
| `open.cabinet`, `open.renew`, `open.support` | открывает кабинет, продление или поддержку: ссылки из заголовков подписки, иначе `links` пакета |
| `open.link` | открывает `url`: https на домене из сертификата или `t.me`, либо `tg:` |
| `subscription.update` | обновляет подписку |
| `check.services` | проверяет через текущее подключение, открываются ли YouTube, Telegram и ChatGPT, и показывает результат |
| `info.card` | показывает карточку из `GET <api>card?id=<id кнопки>` в рамке с вашим именем. Нужен API |

Где кнопки: в обычном V2pn под кнопкой подключения, пока выбран сервер вашей подписки, и в блоке подписки каждого вида вашего оформления, при любой ширине окна. На экране не больше четырёх кнопок: V2pn берёт первые четыре, которые может выполнить, а неизвестное действие, кнопку без нужного поля или кнопку, которой нужен API, когда его нет, пропускает. После подключения V2pn пишет, куда подключился и почему: «Германия 2 — самый быстрый», «Нидерланды — по проверке <провайдер>». Повторное нажатие той же кнопки раньше чем через 3 секунды ничего не делает.

## 4. Закрытые настройки

С правом `lock` провайдер может закрыть настройки своей подписки, как в Happ и INCY: заголовок `hide-settings: 1` или `"lock": true` в пакете. Право выдаётся после ручной проверки: объясните, от чего вы защищаете серверы. Без права заголовки и поле ничего не делают, иначе любая подписка могла бы спрятать от человека, куда идёт его трафик.

Для серверов этой подписки V2pn тогда:

- не показывает адреса, порты и ключи (в списке, таблице, карточке подключения, поиске по адресу);
- не открывает редактор сервера, не даёт поделиться им, скопировать ссылку, показать QR-код, выгрузить конфиг или перенести сервер в другую подписку;
- не кладёт эти серверы в резервную копию (после восстановления их вернёт обновление подписки);
- не даёт менять ссылку подписки, её User-Agent, заголовки и конвертацию и держит ваши значения подключения при запуске и порядка серверов;
- пишет на карточке подписки и в её окне: «Настройки закрыл провайдер <имя>».

`hide-url: 1` (тоже только с правом `lock`) прячет и саму ссылку подписки.

Что у человека остаётся всегда: подключиться и отключиться, выбрать любой сервер подписки, удалить подписку, вернуться в обычный V2pn, свои серверы и маршруты рядом с вашими, kill switch и обновления V2pn.

Защита не абсолютная: конфиг ядра лежит на диске, и опытный человек его прочитает. Цель та же, что у Happ: чтобы адреса нельзя было переслать в два нажатия.

## 5. Заголовки подписки

| Заголовок | |
| --- | --- |
| `v2pn-partner: https://example.com/v2pn/` | папка пакета: https, заканчивается на `/`, без query, на домене из сертификата |
| `v2pn-account-token: <токен>` | необязательный; свой у каждой подписки, до 200 символов из `A–Z a–z 0–9 - _ . ~`; уходит в ваш API как bearer-токен |
| `profile-title`, `subscription-userinfo`, `profile-update-interval`, `support-url`, `profile-web-page-url`, `announce` | стандартные; V2pn показывает их и в обычном виде, и в вашем оформлении |

Другие клиенты заголовки V2pn пропускают.

Если подписка отдаёт целиком конфиг Xray, sing-box или Clash, а не ссылки на серверы, V2pn запускает его только после фильтра. Остаются серверы, маршрутизация между ними, DNS и балансировка. Локальные порты слушают только на `127.0.0.1`. Убирается:

- API ядра, статистика и внешняя панель управления;
- журналы в файлы;
- пути к любым файлам на компьютере;
- TUN: его включает сам V2pn;
- reverse в Xray, а в sing-box — tor и tailscale.

Конфиг для других ядер V2pn из подписки не запускает. Проще всего отдавать V2pn ссылки на серверы.

### Заголовки Happ, INCY и v2RayTun

V2pn читает и те заголовки, которые провайдеры уже отдают для Happ, INCY и v2RayTun, так что панель, настроенная под них, работает в V2pn без изменений. Всё это работает для любой подписки без сертификата, кроме переезда подписки. Регистр в именах заголовков не важен. Текст можно отдавать как есть или как `base64:<UTF-8 в base64>` (кириллицу — только так). Ссылки — только `https:` и `tg:`, остальные V2pn отбрасывает.

| Заголовок | Что делает V2pn |
| --- | --- |
| `announce-url` | кнопка «Подробнее» под объявлением (`announce`) |
| `sub-info-text`, `sub-info-color`, `sub-info-button-text`, `sub-info-button-link` (Happ) | баннер под подпиской в списке, над её серверами, в окне подписки и в вашем оформлении: до 200 символов, кнопка до 25. `red`, `blue` и `green` выбирают красный, синий или зелёный из цветов V2pn, всё остальное — синий. `sub-info-text: 0` убирает баннер. |
| `banner-text`, `banner-button-text`, `banner-button-url` или `banner-url`, `premium-url` (INCY) | тот же баннер, если баннера Happ нет. Кнопка ведёт на `banner-button-url`, иначе на `banner-url`, иначе на `premium-url`. Цвета INCY (`banner-bg-color` и другие) V2pn не берёт. |
| `sub-expire`, `sub-expire-button-link` (Happ); `expiry-banner-text`, `expiry-banner-button-text`, `expiry-banner-button-url` или `expiry-banner-url` (INCY) | напоминание о продлении вместо баннера: за 3 дня до конца срока из `subscription-userinfo` и после него. Ваш текст, если вы отдаёте `expiry-banner-text`, иначе текст V2pn: «Подписка закончится через 2 дн.», «Подписка закончилась». Кнопка «Продлить» ведёт на вашу ссылку продления, иначе на `profile-web-page-url`, иначе кнопки нет. V2pn показывает напоминание и без `sub-expire`; `sub-expire: 0` его выключает. |
| `subscription-autoconnect: 1`, `subscription-autoconnect-type: lastused`, `lowestdelay` или `random` | подключение, когда V2pn запускается выключенным: к последнему серверу этой подписки, к самому быстрому (V2pn сначала проверяет серверы и берёт самый быстрый из ответивших) или к случайному. Работает, если выбранный сервер из этой подписки или сервер не выбран и подписка первая в списке. V2pn, который оставили подключённым, подключается как раньше, а сервер, добавленный человеком вручную, остаётся его выбором. Человек может выключить это для подписки. |
| `subscriptions-sort-type: ping`, `alphabet` или `without` (Happ); `sort-order: ping`, `name` или `none` (INCY) | порядок серверов этой подписки: быстрые сверху, по имени или как вы их отдаёте. Человек может выбрать другой. |
| `subscription-ping-onopen-enabled: 1` | проверка серверов этой подписки при запуске V2pn |
| `update-always: true` (v2RayTun), `subscription-auto-update-open-enable: 1` (Happ) | обновление этой подписки при запуске V2pn. Только этой: Happ обновляет все. |
| `new-url`, `new-domain` | переезд подписки на новый адрес. Только для партнёра V2pn, в сертификате которого есть новый домен, и только в HTTP-заголовках ответа с серверами. Только https; `new-url` важнее `new-domain`, и при ошибке в `new-url` V2pn не переходит к `new-domain`; `new-domain` сохраняет порт, путь и параметры; переезд на тот же домен или на адрес другой подписки V2pn пропускает. Без сертификата заголовки не действуют: иначе подписку мог бы увести любой, кто отвечает по старому адресу. В журнале человек видит, куда переехала подписка. |
| `ping-type`, `check-url-via-proxy` | V2pn их читает и хранит, но пока не применяет: он проверяет каждый сервер через сам сервер по адресу проверки, который выбрал человек |
| `hide-settings`, `hide-url` | закрытые настройки подписки, только для партнёра с правом `lock` (раздел 4); без права V2pn их только хранит |

**В теле подписки.** Как Happ и INCY, V2pn читает строки `#ключ: значение` в начале подписки, которая отдаёт список ссылок, обычным текстом или в base64:

```
#profile-title: base64:S2VzdHJlbCBWUE4=
#sub-info-text: base64:0KHQutC40LTQutCwIDMwJSDQvdCwINCz0L7QtCDQtNC+INC/0Y/RgtC90LjRhtGL
#subscription-autoconnect: 1
vless://…
```

Заголовок важнее той же строки в теле. Только из заголовков: `new-url`, `new-domain`, баннеры INCY и заголовки V2pn. В полном конфиге Xray, sing-box или Clash таких строк V2pn не ищет.

**Что V2pn не берёт.** `routing`, фрагментацию, шум, fronting и другие настройки, которые меняют трафик: им нужна ручная проверка V2pn, они появятся отдельными правами. Цветовые профили, `change-user-agent` и остальные настройки чужих приложений V2pn пропускает.

**User-Agent V2pn.** V2pn скачивает подписку с User-Agent `v2rayN/7.25.6 V2pn/1.0.3`: сначала агент v2rayN, потому что по нему панели выбирают формат, а V2pn читает те же форматы, потом имя и версия V2pn. Если человек задал подписке свой User-Agent, уходит он.

**Правило ответа в Remnawave.** Правила проверяются сверху вниз до первого совпадения, поэтому ставьте это правило выше правил для `v2rayN`. Если вы не партнёр V2pn, уберите `v2pn-partner`. `v2pn-account-token` у каждого человека свой, его отдаёт панель, а не правило.

```json
{
  "name": "V2pn",
  "description": "Баннеры и настройки для V2pn",
  "enabled": true,
  "operator": "AND",
  "conditions": [
    { "headerName": "user-agent", "operator": "CONTAINS", "value": "v2pn", "caseSensitive": false }
  ],
  "responseType": "XRAY_BASE64",
  "responseModifications": {
    "applyHeadersToEnd": true,
    "headers": [
      { "key": "v2pn-partner", "value": "https://example.com/v2pn/" },
```

## 6. Ссылки

`v2pn://add?url=<ссылка на подписку, в URL-кодировке>&name=<имя>` открывает V2pn, и он спрашивает, добавить ли подписку. V2pn принимает и ссылки Happ (`happ://add/<ссылка>`), v2RayTun (`v2raytun://import/<ссылка>`) и Hiddify (`hiddify://import/<ссылка>`). Если такая подписка уже есть, V2pn просто говорит об этом. В Windows схему `v2pn` регистрирует установленное приложение, на macOS — пакет приложения.

## 7. API (необязательно)

С правом `account` и адресом `api` на домене из сертификата V2pn спрашивает:

`GET <api>account` с заголовком `Authorization: Bearer <v2pn-account-token>`, когда открывается оформление, и дальше раз в 30 минут, пока оно на экране:

```json
{
  "plan": "Личный",
  "status": "ACTIVE",
  "servers": { "healthy": 11, "total": 14 },
  "devices": { "count": 2, "limit": 5 },
  "until": "2027-01-31",
  "note": "В воскресенье ночью плановые работы."
}
```

`GET <api>status` без токена, раз в 15 минут:

```json
{ "incidents": [ { "title": "Германия не отвечает", "text": "Уже чиним.", "severity": "major" } ] }
```

Для кнопок и описания серверов (право `actions`) V2pn спрашивает ещё, всегда с токеном подписки, если он есть:

`GET <api>servers` — так же часто, как `account`: при открытии оформления или когда выбран сервер вашей подписки, и не чаще раза в 30 минут. Те же поля, что в `servers` пакета, плюс `load` (0–100) и `healthy`. Значения API важнее значений пакета, поле за полем:

```json
{ "servers": [ { "name": "🇩🇪 Германия 2", "load": 31, "healthy": true }, { "host": "nl1.example.com", "load": 90, "healthy": false } ] }
```

`GET <api>recommend?purpose=youtube` — при нажатии кнопки `connect.recommend`: серверы по порядку, лучший первым (имена или адреса, до 50):

```json
{ "servers": ["🇳🇱 Нидерланды", "🇩🇪 Германия 2"] }
```

`GET <api>card?id=plan` — при нажатии кнопки `info.card` с этим `id`: заголовок до 60 символов и простой текст до 600, переносы строк сохраняются, разметки нет:

```json
{ "title": "Тариф «Семья»", "text": "5 устройств, без ограничения трафика.\nОплачено до 31 января 2027." }
```

Все поля необязательны: V2pn берёт то, что знает, остальное пропускает. Ответ — JSON до 64 КБ с кодом 200, всё остальное считается отсутствием ответа. С токеном V2pn не идёт по редиректам. Если ваш сайт там, где человек, заблокирован, V2pn повторит запрос через VPN. `servers.healthy`/`total` заменяют в оформлении счёт по пингу V2pn («11 из 14 по проверке <провайдер>»). Отдавайте только числа, без адресов серверов и учётных данных.

## 8. Виды

| Вид | Что это |
| --- | --- |
| `signature` | обычный V2pn с вашим логотипом рядом со знаком V2pn в заголовке |
| `warm` | раскладка V2pn в ваших цветах и шрифте Geist |
| `cabinet` | раскладка личного кабинета: светлая карточка с местом, состоянием и квадратиками серверов, ниже серверы и маршрут |
| `studio` | раскладка сайта: место пиксельными буквами, капсула с кнопкой подключения, ваша картинка горит, пока защита включена |
| `ascii` | весь экран текстом: напечатанная карта, значения моноширинной таблицей, кнопки в скобках |

V2pn рисует все пять при любой ширине окна, в светлом и тёмном варианте. Человек настраивает каждый вид на странице «Оформление»; обычный V2pn эти настройки не меняют.

Что пакет поменять не может: цвета и плашку состояния (зелёное «защищено», красное «не защищено»), кнопку подключения, знак V2pn и пометку «на V2pn», переключатель обратно в обычный V2pn, настройки и маршрутизацию.

## 9. Жизнь партнёрства

- **Обновления.** Меняйте и переподписывайте пакет когда угодно: V2pn заберёт его при следующем обновлении подписки.
- **Срок.** Сертификат действует год. V2pn проверяет его при запуске и каждый час; когда срок выходит, оформление закрывается с пояснением и открывается обычный V2pn. Просите новый за месяц, `tools/partner-check.cs` предупредит.
- **Уход.** Перестаньте отдавать `v2pn-partner`, и оформление пропадёт при следующем обновлении. Если человек удалит вашу подписку, вместе с ней уйдёт и оформление.
- **Отзыв.** Владелец V2pn может отозвать сертификат до срока; установленные приложения узнают об этом из канала релизов и закроют оформление.

## 10. Проверка

```
dotnet run tools/partner-check.cs -- https://example.com/s/<токен настоящей подписки>
dotnet run tools/partner-check.cs -- --folder ./v2pn --subscription https://example.com/s/<токен>
```

Скрипт выполняет проверки самого V2pn с ключами, встроенными в приложение, и на каждом шаге пишет OK или что не так: заголовки, сертификат, подписи, домены, картинки, описание серверов и кнопки (что V2pn пропустит и почему), закрытые настройки, API, включая `servers`, `recommend` и `card` для ваших кнопок.

Пример пакета с описанием серверов и кнопками и локальный сервер с подпиской, пакетом и API для предпросмотра лежат в `tools/demo/partner/partner.json` и `tools/demo/demo_partner.py`.

Чтобы увидеть оформление до публикации, попросите у владельца V2pn сертификат для предпросмотра на `127.0.0.1`, отдавайте пакет и тестовую подписку со своего компьютера по http и включите в V2pn режим разработчика (О программе → обновления). Тогда V2pn примет пакет с `127.0.0.1`.

## Приватность

V2pn не отправляет вашим серверам ничего сверх того, что отправил бы любой подписке: пакет и API запрашиваются так же, как сама подписка, с user agent V2pn, а для `account` ещё с токеном, который выдали вы. Трафик человека, его другие подписки, устройство и всё, что V2pn измеряет, никуда не отправляются.
