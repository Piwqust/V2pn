        Кнопка «Подключить в V2pn»

        Добавьте в бота и в кабинет кнопку со ссылкой ниже. В конец ссылки подставьте подписку этого человека.

        Подписка идёт после #: эта часть остаётся в браузере человека, не уходит на сервер V2pn и не попадает в логи.

        Пример для Telegram-бота

        Обычная inline-кнопка со ссылкой. Подписку закодируйте, как любой параметр ссылки.

        Интеграция — ступень 2
        
              
        На ступени 2 человек входит в V2pn по коду из вашего бота, ничего не копируя, а во вкладке появляются ваши кнопки. Для этого на вашем сервере нужны два адреса API.
        
            
        
            
          
              
        • Вход по кодуV2pn показывает шесть цифр, человек подтверждает их в боте.
          • 
              
        • Свои кнопкиДо четырёх: «Самый быстрый», «Для YouTube», «Продлить».
          • 
              
        • Скрытые адресаЧеловек не видит адреса и ключи ваших серверов.
          • 
            
        
            
        
          
        
          
        
            
        
            
        
              
        Адрес API
        
              
        
                
                
        
                На одном из ваших доменов. V2pn добавляет к нему login/start и login/poll.
                
              
        
              
        
              
              
              
              
            
        
            
        
              
        Два адреса на вашем сервере
        V2pn обращается к ним сам, с User-Agent V2pn. Ответ — JSON с кодом 200.
        
              
        
                
        1. Начать вход POST {api}login/start
        
                
        V2pn просит код, когда человек открывает вход. В теле — система и имя компьютера, чтобы бот сказал, кто входит.
        
                
        // запрос
{ "device": "Windows · DESKTOP-7Q2", "app": "V2pn 1.2.2" }
// ответ
{ "code": "482913",
  "token": "от 32 до 256 символов: A–Z a–z 0–9 - _ . ~",
  "url": "https://t.me/kestrel_bot?start=v2pn-482913",
  "expires": 600 }
        
              
        
              
        
                
        2. Проверить вход GET {api}login/poll?token=…
        
                
        V2pn спрашивает раз в 2 секунды, пока человек не подтвердит код в боте.
        
                
        { "state": "waiting" }
{ "state": "done", "subscription": "https://sub.example.com/s/…", "name": "Kestrel" }
{ "state": "expired" }
        
              
        
              
        Подробно, с правилами для бота: руководство, «Вход по коду».
