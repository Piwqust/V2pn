V2pn ищет другие клиенты при запуске и в меню ☰, «Сервис», «Перенести из другой программы». Если находит, первая карточка предлагает перенос: программы списком, у каждой видно, что в ней есть.

## v2rayN

V2pn хранит данные в тех же файлах, что и v2rayN, поэтому переезд занимает одну кнопку: серверы, подписки, маршруты и настройки. Установка одной командой переносит сама.

- v2rayN закрывается и перестаёт запускаться вместе с системой. Его файлы не меняются, к нему можно вернуться.
- То, что было в V2pn до переезда, сохраняется в `guiTemps\V2pnImportBackup-<дата>`.
- Ядра, которых нет у V2pn, берутся из папки v2rayN.
- v2rayN, запущенный от администратора, V2pn закрыть не может: тогда он попросит выйти из v2rayN через значок в трее.

## Другие программы

| Программа | Что переносится |
| --- | --- |
| Clash Verge (Rev), Clash Nyanpasu, Clash Party, Clash for Windows | подписки и серверы профилей |
| FlClash, FlClashX | подписки и серверы |
| NekoRay, NekoBox, Throne | группы с подпиской и серверы |
| Hiddify | подписки и серверы |
| v2RayTun | подписки и серверы |
| Karing | подписки |
| GUI.for.Clash, GUI.for.SingBox | подписки |
| Happ | ничего: данные зашифрованы, скопируйте ссылку в самом Happ |

Файлы других программ V2pn только читает, работающую программу не трогает. Сервер или подписка, которые уже есть в V2pn, второй раз не добавляются.
